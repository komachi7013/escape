# 3ステージの制作仕様（解答を含む）

元の引き継ぎ資料は1ステージでした。2026年10月3日の追加依頼で、探索・発見・物の移動・暗号を中心に2ステージを追加し、3つの部屋を順に進む構成に変更しました。既存の第1ステージの謎は保持しています。

## 第1ステージ：旅人の客室

天体の数（太陽2・月4・星3）をメモの順に入力して243で引き出しを開く。入手した紙片の葉→波→炎を本棚に入力し、紋章を取得する。紋章を宝箱に使い、旗の月→王冠→太陽→星の順を入力して鍵を取得する。扉に鍵を使い、脱出すると第2ステージへ進める。

## 第2ステージ：薬草の物置

入力順を当てる仕掛けから、隠れた物の探索と配置・光の誘導へ変化させました。

1. **木箱の下の発見**：床の擦れた跡を頼りに木箱を横へドラッグし、隠れていた鏡を取る。ボタンでも同じ操作が可能。部屋の木箱も実際に移動する。
2. **敷物の下の配置図**：敷物をめくると「葉→水、花→光、実→土」が見える。鉢を対応する台座へドラッグする。選択して「ここへ置く」でも操作できる。誤配置は自由に修正でき、別の鉢がある台座に動かすと入れ替わる。配置図の発見と正しい配置で、鏡台の覆いが開く。
3. **鏡による光の誘導**：窓の「光は葉の扉へ」という刻印を読む。鏡を選択して鏡台に使い、向きを右へ回す。部屋に光路が表示され、葉の隠し戸が開く。隠し戸を調べて鍵を取り、出口へ進む。

鍵は自動で所持品に転送せず、開いた隠し戸を調べて取る構成にしています。「動かす→発見する→取りに行く」を遊びの中心に置いています。

## 第3ステージ：星見の書斎

隠れた道具、文字を変換する暗号、望遠鏡の方向と符号表を組み合わせます。

1. **地球儀の下の道具**：地球儀の脚の下に円盤の縁が見える。地球儀を横へ動かし、解読円盤を取得する。星図もずらすと裏から「３歩、文字を戻せ」が見つかる。
2. **ずらし暗号**：円盤を暗号机に使い、刻まれたPRRQを3文字戻すとMOONになる。円盤の位置と解読した単語を合わせて入力する。解読に成功すると星図の月の小箱が開き、調べるとレンズを取得できる。生成画像の文字は使わず、アルファベットをコードで変換して表示する。
3. **星の点と線**：レンズを望遠鏡に使う。星図の「白鳥・北東」を頼りに方位盤をドラッグし、北東へ向けると観測記録が現れる。−・− / ・ / −・−− を部屋の符号表と照合するとKEYになる。入力すると望遠鏡の収納から最後の鍵を取得する。扉に使うと完全脱出成功。

## 進行・保存・ヒント

- 各部屋のクリア画面から次へ進む。第3ステージで全体の成功画面を表示する。
- 所持品は部屋ごとに管理し、使った鏡・円盤・レンズ・鍵を復活させない。
- 配置、動かした物、角度、解読結果、現在の部屋、ヒントを保存する。
- 旧version 1データはversion 2へ移行し、第1ステージの途中・脱出後を引き継ぐ。破損や不整合は到達可能な状態へ正規化する。
- 各ステージの各主要ギミックに3段階のヒントを用意。最終ヒントは確認後に答えを表示する。
- 全ての移動操作にはドラッグ以外の操作方法を用意する。望遠鏡の方位はスライダーでも変更できる。

## BGM

タイトル曲「宿屋の朝」と、客室・物置・書斎それぞれの旋律をオリジナルで作成。柔らかなベル、ピチカート、低音、タイトルのフルート風の重なりをWeb Audioで合成する。各テーマは96 BPM、80秒の循環するフレーズ。タイトルから再生を試み、自動再生を制限するブラウザーではタイトルの再生ボタンまたは最初の操作で開始する。多重再生を避けて1つのAudioContextとスケジューラを共有する。タイトルで消音した設定も保持する。
