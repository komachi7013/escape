- `npm test`：3つのテスト成功。謎の依存関係、誤入力、正解、アイテムの重複取得・消費、脱出、保存の検証・復元、家具との距離を含む移動経路を確認。
- Chrome 154.0.8037.98 / Playwright：1280×720 と1920×1080。実際のWebGL描画とDOM操作で通しプレイ成功。スクリーンショットを目視確認。
- タイトルに扉に向き合う3D旅人の後ろ姿、開始時のカメラ移動、固定方向の部屋全体表示。
- 必要な8対象の調査。壁の絵に太陽2・月4・星3、メモに太陽→月→星、紙片に葉→波→炎、旗に月→王冠→太陽→星を表示。
- 243入力→紙片、葉→波→炎→紋章、紋章使用→月→王冠→太陽→星→鍵、鍵使用→開ける→脱出成功。

- ヒントの段階表示、答え表示前の確認、開示状況の保存。

## 例外時の扱い

保存が禁止されても警告を表示し、その場でのゲーム進行を継続します。破損した保存データは安全な初期状態に戻します。画像読み込み失敗、WebGL非対応、WebGL context loss はメッセージと再読み込みボタンを表示します。これらは実際に障害を注入してブラウザーで検証しています。

## 未確認・制約

- Firefox / Safari / Edge は未検証。モバイル向けの操作最適化は範囲外。
- 初見10〜15分のプレイ時間は企画目標。答えを知った自動操作での検証であり、初見プレイヤーによる時間測定はしていません。
- BGMの作曲・再生・信号・設定は検証しましたが、スピーカーで聴いた音色・音量の印象や80秒の接続部の聴感評価は未確認です。音源は外部楽曲を使用せずオリジナルの合成音です。
- 最新の追加依頼により全3ステージに拡張しました。外部GLB、戦闘、自由移動・自由カメラは追加していません。部屋とキャラクターはスタイルを揃えたオリジナルの3D形状です。
- ローカル保存はブラウザー・配信元ごとに独立し、ブラウザーのデータ削除で失われます。
- 外部公開、デプロイ、有料素材購入は実施していません。
