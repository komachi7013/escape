# 古い宿屋からの脱出

中世ファンタジーの宿屋を舞台にした、日本語・PCブラウザー向けの全3ステージの3D脱出ゲーム。Three.js で部屋・家具・旅人を描画します。客室の入力の謎、物置の探索と配置、書斎の文字と星の暗号を解いて、宿屋の外へ進みます。

## 起動

```sh
npm ci
npm run dev
```

表示されたローカル URL（通常 `http://127.0.0.1:5173`）をブラウザーで開きます。Node.js 20.19 以上または 22.12 以上が必要です。制作環境は Node.js 24.19.0 / npm 11.17.0。依存関係の実際のバージョンは `package-lock.json` で固定しています。

```sh
npm run build
npm run preview
```

`dist/` が静的配信可能な出力です。WebGL 2 が必要です。HTMLを `file://` で直接開かず、HTTPサーバーを使ってください。外部アカウントやバックエンドは不要です。

## 遊び方

- 部屋の光るひし形をクリックすると、旅人がその小道具の手前まで歩いてから調べます。印にマウスを重ねると対象名が表示されます。
- 調査画面で手掛かりを読み、数字錠や本、宝箱のボタンを操作します。
- 所持品を選んで対象を調べると、到着後に使用します。紙片は選択後の「紙片を読む」から再確認できます。
- ホイール、＋／−で1〜2倍に拡大縮小します。拡大後に対象を選ぶと、その場所に注視点が移ります。「全体表示」で戻します。視点の回転はありません。
- ヒントは3段階。答えを表示する前には確認画面が出ます。
- 全画面は専用ボタンで切り替えます。Escで調査画面を閉じたり、アイテムの選択を解除できます。
- 進行とヒント、BGM・効果音の音量とミュートは自動保存されます。同じブラウザーと同じ配信元で「続きから」を選んでください。
- 「最初から」「もう一度遊ぶ」は確認後に進行を初期化し、音量設定を保持します。
- 第1・第2ステージの脱出画面では、次のステージへ進めます。部屋の途中でも進行と現在のステージを保存します。旧版の第1ステージの保存データも引き継ぎます。
- 木箱や鉢、地球儀をドラッグして動かせます。鉢は選択して「ここへ置く」でも操作できます。鏡や望遠鏡の向き、解読円盤はドラッグまたはスライダーで調整できます。
- タイトル表示時にオリジナルBGM「宿屋の朝」の再生を試みます。自動再生を制限するブラウザーでは、タイトルの「BGMを再生」か最初の操作で開始します。音の設定は保持され、タイトルと各部屋で旋律が切り替わります。

## ステージ

| 部屋 | 主な体験 |
| --- | --- |
| 1. 旅人の客室 | 天体の数・本の順序・紋章の入力を使って脱出 |
| 2. 薬草の物置 | 木箱・敷物を動かして発見、植物の配置、鏡による光の誘導 |
| 3. 星見の書斎 | 地球儀・星図の裏を探索、ずらし暗号、望遠鏡と星の点線暗号 |

## 検証

```sh
npm test
npm run test:browser
```

ブラウザーテストは開発サーバーを別ターミナルで起動した状態で実行します。インストール済みの Google Chrome を Playwright から起動します。別の配信元は `GAME_URL=http://127.0.0.1:4173 npm run test:browser`、画面を表示して実行する場合は `HEADED=1 npm run test:browser` を使います。

配信ビルドの簡易検証は `npm run preview -- --port 4173` の起動中に `node tests/build-smoke.mjs` で行えます。

通しプレイ、保存復元、誤入力、アイテム使用、ヒント、ズーム、全画面、画面リサイズを操作で検証し、`artifacts/playtest/` にスクリーンショットと結果を保存します。検証範囲と未確認事項は `docs/verification.md` に記載しています。

## 構成

| 場所 | 内容 |
| --- | --- |
| `src/simulation/` | 描画から独立した進行、アイテム、保存の検証、移動経路 |
| `src/render/room.ts` / `additionalRooms.ts` | Three.js の3つの部屋、3D旅人、家具の移動と光、固定方向カメラ |
| `src/ui/additionalPuzzles.ts` | 移動・配置・鏡・解読円盤・望遠鏡の操作と調査画面 |
| `src/main.ts` / `src/ui/style.css` | DOM の調査画面、所持品、メニュー、ヒント、設定 |
| `src/audio.ts` | Web Audio によるタイトル＋各部屋の80秒BGMと効果音 |
| `public/assets/` | 実際にゲームで使う8つの透過画像 |
| `assets/` | 生成画像の原本、プロンプト、透過処理の出力・QC記録 |
| `tests/` | 進行と移動の自動テスト、Chrome通しプレイ |
| `docs/` | 引き継ぎ資料の参照用コピー、制作・素材・検証の記録 |

モデルはオリジナルのThree.js形状で構成しており、GLBの外部依存はありません。謎の記号数・順序と日本語ラベルはCanvas/DOMから描画し、生成画像の文字に依存しません。生成された紙片画像のインク模様は装飾です。答えとなる紙片は調査画面に表示します。

## 画像の制作

ImageGen の組み込みツールで2×2の所持品パックを生成し、指定された generate2dsprite のプロセッサーでマゼンタ背景の除去、切り出し、整列、strict QC を行いました。Python実行には `.venv/bin/python` のみを使用しています。

この作業用チェックアウトの `.venv` は、既存の `/Users/komachi/work/escape/.venv` を参照しています（Git管理対象外）。ゲームを遊ぶためにPythonは必要ありません。画像を再処理するには Pillow と NumPy を利用できるPython環境、および指定スキルのプロセッサーが必要です。

```sh
.venv/bin/python /Users/komachi/work/escape/.codex/skills/generate2dsprite/scripts/generate2dsprite.py process \
  --input assets/source/inventory-raw.png --target asset --mode prop_pack_2x2 \
  --rows 2 --cols 2 --output-dir assets/inventory --cell-size 192 \
  --fit-scale 0.82 --align center --component-mode all --strict-qc
```

素材の出典とライセンスは `docs/credits.md`、生成プロンプトは `assets/inventory/prompt-used.txt` を参照してください。制作仕様は `docs/handover-reference.md` を参照しました。外部公開や有料素材の購入は行っていません。
